# Credit-Risk-Modelling
🚀 Credit Risk Modeling Project – Predicting Loan Default Probability

Excited to share my latest Data Analytics & Machine Learning project where I built a Credit Risk Prediction Model to identify the probability of a borrower defaulting on a loan.

🔍 Project Highlights:

Worked on real-world financial and credit datasets
Performed data cleaning, preprocessing, and feature engineering
Created meaningful features like credit utilization rate
Built and compared ML models such as Logistic Regression & advanced models
Generated predictions to classify high-risk vs low-risk borrowers

📊 Key Outcomes:

Developed a model that helps financial institutions reduce risk and improve decision-making
Transformed raw financial data into actionable insights
Built a structured pipeline from data → model → prediction

💡 Tools & Technologies Used:
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn

📌 What I Learned:

How real-world financial data is analyzed
Importance of feature engineering in improving model performance
End-to-end ML workflow from preprocessing to deployment
